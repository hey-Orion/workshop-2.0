**1. Practice in interview conditions.**
Use a plain editor with autocomplete off. If your editor finishes `groupby` for you, you won't learn to type it, and interviews often use bare editors.

**2. Do short sessions, twice a day.**
Two 30-minute sessions beat one 3-hour block. Syntax memory builds across sleep, so spread the repetitions over more days instead of cramming them into one.

**3. Type everything, never paste.**
After checking an answer, retype the correct version yourself 2-3 times. Typing is what builds the muscle memory.

**4. Keep a syntax log, and reread it every day.**
Write each mistake as the correct line, for example `df.groupby("x").agg(total=("amount", "sum"))`. After a week you'll have a short list of your own recurring slips, which is more useful than any cheat sheet.

**5. Time-box yourself.**
Give each question 10 minutes. If you're stuck, write a comment describing your plan, then look at the solution, cover it, and retry. Struggling for 40 minutes teaches less than 10 minutes plus a check.

**6. Mix up the order.**
Don't do 5 SQL questions in a row and then 5 Pandas. Alternate SQL, Pandas, Python. Switching makes you recall the syntax each time, which sticks better than repeating one tool.

**7. Change the question after you solve it.**
Add a filter, swap a column, or reverse the sort. If you can still write it cold, you know the pattern and haven't just memorized the text.

**8. Use your own project as practice material.**
Rewrite pieces of Dataflow-Sentinel from scratch, such as the Silver validation function or the BigQuery export. Real code you care about sticks better than exercises.

**9. Say it out loud as you type.**
"Group by customer, sum the amount, then sort." This builds the interview habit at the same time.

**10. Use the docs, not AI, when you're stuck on syntax.**
Search for the function's docs page and read the example. Looking it up yourself sticks better than getting the answer handed over, and it's what you'll do on the job.

**What not to do**
Don't read solutions without attempting first, don't add new resources, and don't skip the day-two repeat.
